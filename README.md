# GUI CeTZ

**Edit Typst CeTZ drawings visually in VS Code, while keeping your code editable.**

Move shapes, adjust curve handles, and change colors or line styles in [Draw.io Integration](https://github.com/hediet/vscode-drawio). Your edits update the original `.typ` file, and Typst and CeTZ render the result.

![A circle selected in the actual editor, with position and radius controls visible](docs/images/screenshots/03-select-circle.jpg)

## What you can do

- **Draw in 2D:** use 15 tools for rectangles, circles, text, lines, arcs, curves, and more.
- **Edit shapes:** move, resize or rotate supported geometry; adjust control points and properties; copy, paste, group, and align objects.
- **Build connected diagrams:** create connectors that follow shapes, shared anchors, Boolean combinations, cutouts, and frames.
- **Work in 3D:** draw on a plane in 2D, then position and tilt it in 3D. Add lines and text with XYZ coordinates, and adjust the camera.
- **Switch between code and GUI:** select the matching source, undo and redo edits, and export PDF, SVG, or PNG.

The `.typ` file is the document you save. The Draw.io editing document is generated in memory, so save your Typst source to keep your work.

## Install

You need **VS Code 1.90.0 or later**, **Draw.io Integration** (`hediet.vscode-drawio`), and the **Typst CLI** available to VS Code.

To package the extension from this repository, you also need Node.js and npm. Run these commands from the repository root:

```sh
npx @vscode/vsce package
code --install-extension gui-cetz-0.2.0.vsix
```

The VSIX version follows `package.json`. You can also use **Extensions → … → Install from VSIX…** in VS Code. When you first open the editor, allow the CeTZ plugin in Draw.io's trust dialog.

For setup checks, updates, and running from source, see the [installation guide (Japanese)](docs/installation.md).

## Open your first drawing

Save this as `hello.typ`. The first compilation needs network access if the CeTZ package has not been downloaded yet.

```typst
#import "@preview/cetz:0.5.3"
#set page(width: auto, height: auto, margin: 12pt)

#cetz.canvas({
  import cetz.draw: *
  rect((0, 0), (3, 2), fill: blue.lighten(85%))
  circle((1.5, 1), radius: 0.5, fill: orange)
  content((1.5, 2.5), [Hello CeTZ])
})
```

1. Click **▶ GUI CeTZ** above `cetz.canvas`, or run **CeTZ: Open GUI Editor** from the Command Palette.
2. Select a shape and drag it to move it. Use **Properties** on the left to change coordinates, colors, and line widths.
3. Choose a shape icon on the right, then click the canvas to place its points.
4. Check the updated `.typ` file and save it.

Follow the [first drawing tutorial (Japanese)](docs/tutorials/01-first-drawing.md) for step-by-step exercises with coordinates and sample files.

## Editing scope

GUI operations apply where the extension can map a change back to its source safely. Shapes generated by loops, complex transforms, or expressions may require source editing while you inspect the rendered preview. Changes without a safe source mapping are rejected.

Existing CeTZ imports are preserved. Boolean operations require CeTZ 0.5.2 or later; some function names differ between 0.4.2 and 0.5.x. See [compatibility and limitations](docs/source-and-limitations.md) for details.
