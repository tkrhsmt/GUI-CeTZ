# 配置・グループ・接続

[ドキュメント一覧](README.md) · [接続図のチュートリアル](tutorials/02-connected-diagram.md)

## コピー・貼り付け・複製

図形やグループを選択してCeTZメニュー／右クリックメニューの **Copy / Paste**、またはコピー・貼り付けのショートカットを使います。**Duplicate** は選択物を複製します。

コピーにはTypstコードを使うため、別のCeTZキャンバスへ貼り付けたり、元の図形を削除した後に貼り付けたりできます。名前が衝突する場合は貼り付けた図形の名前を変更し、コピーした図形同士の参照も追従させます。

貼り付けるたび、元の位置から右下へ0.5 CeTZ単位ずつずらします。同じクリップボードを続けて貼り付けるとずれが増え、コピーし直すと初期化します。貼り付けた図形はまとめて選択されるので、そのまま移動できます。文字入力欄では通常のテキストコピー／貼り付けになります。

## 整列と等間隔配置

複数図形を選び、CeTZメニューから整列します。

| メニュー | 揃える位置 |
| --- | --- |
| Align left / centers / right | 左端／横方向の中心／右端 |
| Align top / middles / bottom | 上端／縦方向の中心／下端 |
| Distribute horizontally / vertically | 横方向／縦方向に分布させる |

配置変更は、対応するリテラル座標へ書き戻せる図形が対象です。式に基づく位置や複雑な変換ではソース編集が必要な場合があります。

## 重なり順

**Bring forward / Send backward**、Outlineの上下ボタン、行のドラッグで、同じキャンバスまたはグループ内の順序を変更できます。Outlineはソースの記述順です。

CeTZでは、先に定義したアンカーや`set-style`、変換などが後続要素に影響します。そのため、依存関係に反する入れ替えや、途中の状態変更をまたぐ並び替えは適用されません。3Dで`sorted: true`を指定したビューは深度ソートを優先します。ソース順で描きたい場合は[3D編集](3d-guide.md)を参照してください。

## グループ化

複数図形を選び、**Group selected** を使います。グループを選び **Ungroup selected** で解除します。認識されたグループの子図形は、Outlineから個別に選択して編集できます。

グループ化では`group(name: ..., { ... })`を生成し、外部からの名前付きアンカー参照を新しいグループ名に合わせます。選択した図形がソース上で隣接していない場合にも対応しますが、間にコメント、状態を変える文、途中の定義への依存がある場合は、ソースで構造を調整してください。

![接続前の2つの長方形と円を表示した実画面](images/screenshots/16-connection-start.jpg)

ここでは左と中央の長方形をつなぐ例を使います。名前はOutlineで確認できます。

## 移動に追従する接続線

1. 長方形または円を2つ選びます。
2. 左側の接続コントロールで **From anchor** と **To anchor** を選びます。
3. **Route** を`straight`または`elbow`にして、**Connect selected shapes** を押します。

![2つの長方形を選択し、From anchor、To anchor、Routeと接続ボタンを表示した画面](images/screenshots/17-connect-controls.jpg)

**操作：** 2図形を選んで左パネルを下へスクロールします。画像はFrom／Toが`auto`、Routeが`straight`の例です。**Connect selected shapes** を押して接続します。

アンカー位置は`auto`、`north`、`east`、`south`、`west`から選べます。CeTZメニューの **Connect selected (straight / elbow)** からも作成できます。

必要に応じて図形へ名前を付け、名前付きアンカーを参照する線を生成します。生成後に図形を動かすと、接続線も追従します。接続の始点・終点は生成された`line`とFrom/Toの表示で確認してください。

例えば、ソースでは次のように関係を表せます。

```typst
rect((0, 0), (2, 1), name: "input")
rect((4, 0), (6, 1), name: "output")
line("input.east", "output.west", mark: (end: ">"))
```

![長方形同士の間に矢印付きの接続線が作られた画面](images/screenshots/18-connector-created.jpg)

**結果：** 2図形の間に、名前付きアンカーを参照する接続線が追加されます。

接続先を変更するには、接続線と新しい長方形または円を選びます。**Reconnect end** で始点／終点、**Target anchor** で辺を選び、**Reconnect to selected shape** を押します。elbow接続は既存の曲がり位置の比率を維持します。

Draw.io標準の接続エッジを直接作る操作には、CeTZへの書き戻し対応がありません。CeTZの接続コマンドを使ってください。

![中央の長方形を上に動かすと矢印も追従している画面](images/screenshots/19-connector-follows.jpg)

**操作：** 選択を解除してから中央の長方形を上へドラッグします。線の端点が追従すれば、関係を保った接続になっています。

## 複数の図形で点を共有する

共有点は`anchor("P", (x, y))`を定義して、各図形から`"P"`を参照します。共有点のハンドルを動かすと、参照している図形が次の描画で追従します。

| 操作 | 用途 |
| --- | --- |
| Share first literal point | 選択図形の最初の数値座標を共有アンカーにする |
| Auto-share coincident points | 複数図形で同一の数値座標を共有アンカーにまとめる |
| Propertiesの共有点操作 | 対応する点を共有、アンカー名の変更、参照の切り離し |

切り離しは参照をその時点の数値座標に戻すため、その点は以後アンカーに追従しません。共有点の作成・名前変更などにはトップレベルのリテラル座標を使う制約があります。`let`や辞書で共有している点、計算式のアンカーはソースで編集します。
