# GUI CeTZ ドキュメント

GUI CeTZは、CeTZのコードを保存形式として使うVS Code拡張機能です。導入から2D・3D作図、ソースとの連携、開発方法まで説明します。ボタン名は実際の英語表記に合わせています。

![GUI CeTZの実際の2D画面。左にOutline、中央に図形、右に描画ツール](images/screenshots/02-editor-overview.jpg)

実際の編集画面です。以下のガイドでは、この画面で何を選び、どこへ入力するかをスクリーンショットで追えます。

## 初めて使う方へ

1. [インストール](installation.md)で必要なソフトを用意します。
2. [チュートリアル1](tutorials/01-first-drawing.md)で図形を追加・移動し、色と文字を変更します。
3. [チュートリアル2](tutorials/02-connected-diagram.md)で移動に追従する接続線を作ります。
4. [チュートリアル3](tutorials/03-path-design.md)で切り抜きと囲み枠を使います。
5. [チュートリアル4](tutorials/04-3d-workspace.md)で2Dの図を3D空間へ配置します。

各チュートリアルには開始用の`.typ`ファイルがあります。自分の作業場所へコピーしてから試すと、元の教材を残せます。

## 用語

| 用語 | 意味 |
| --- | --- |
| キャンバス | `.typ`内の1つの`cetz.canvas({ ... })`。1ファイルに複数置けます。 |
| ソース | 保存対象となるTypstコード。GUIの変更はこのコードへ反映されます。 |
| リテラル | `(1, 2)`、`0.5`など、式の計算なしに値が読める記述。 |
| アンカー | `"node.east"`や`"P"`のような、図形上の点・共有点の参照。 |
| 制御点 | 線の頂点や曲線の形状を操作するための点。 |
| 投影ビュー | `ortho`または`perspective`で定義された3Dの見え方。 |
| 描画平面 | `on-xy`などで定義された、2D作図を行う面。 |
| ローカル座標 | 選択平面の中で使うX/Y。空間全体のXYZとは区別します。 |
