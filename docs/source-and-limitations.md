# ソースとの連携・互換性・制約

[ドキュメント一覧](README.md)

## ソースを基準にする仕組み

保存対象は`.typ`で、GUI表示はそこから生成します。単純な長方形も高度な曲線も、TypstとCeTZが描画したSVGを使います。編集できる呼び出しには選択枠やハンドルを重ね、変更を対応するソース範囲へ書き戻します。

移動では座標、プロパティ変更では対象引数、削除では対象呼び出しを変更します。編集対象外の式、コメント、本文をできるだけ維持します。ただし、グループ化・パス合成・3D化のような構造操作は、必要なラッパーや名前、補助コードを生成します。元の書式が完全に不変という意味ではありません。

## GUIで扱える範囲

| ソースの形 | GUIでの扱い |
| --- | --- |
| トップレベルの数値座標を持つ基本図形 | 移動、対応するサイズ変更・回転・スタイル・削除 |
| 数値座標の線・曲線・円弧など | 図形ごとの選択枠と対応する点ハンドル、引数編集 |
| 名前付きアンカー、相対座標、前の点、補間、座標式を使う基本図形 | 解決できる場合は表示・移動。元参照を維持して相対オフセットを加える。サイズ変更はソースで行う |
| `anchor("P", (x, y))` | 点ハンドル、対応する共有・改名・切り離し |
| 認識された`group`の子図形 | 子ごとの選択・対応する編集、グループ化と解除 |
| `boolean`などのパス操作 | 選択から作成、対応する引数や本体の編集 |
| 3Dの認識された平面 | 平面の姿勢変更、2Dローカル表示での編集 |
| 投影直下のXYZの線・文字 | 対応するXYZハンドル、座標・文字・外観の編集 |
| ループ、動的な本体、未対応変換、解決できない境界 | Typstのプレビューで確認し、ソースで編集 |

関数名が対応していても、座標や変換の書き方により操作範囲は変わります。描画自体が成功していても、図形を個別に対応付けられない場合は固定のプレビューになることがあります。

## 受け付けない操作の例

- アンカー式で決まる図形の枠を引き伸ばす。
- 星を縦横別の倍率で変形する。
- 文字の枠を伸ばしてフォントサイズを変更する。
- Draw.io標準の接続エッジを作る、既存の線の点数をGUI上で変える。
- 対応するCeTZ引数を持たないDraw.ioのスタイルを設定する。
- アンカー定義より前へ利用箇所を移す、途中の状態変更を越えて順序を変える。
- 外から参照されるBoolean入力を消費する、平面外の参照先が変わる構造操作を行う。

安全に書き戻せない操作は適用せず、現在のTypstから表示を復元します。Propertiesの式欄やソースで調整してください。

## グループ・状態・参照

`set-style`、変換、変数定義などは後続の意味を変えます。見た目が同じ位置の図形でも、並び替え可能とは限りません。グループ化は名前空間を変えるので、対応する外部参照も修正します。平面の管理用ラッパーには`scope`を使い、余計な名前空間を作らないようにします。

共有点としてGUIが扱うのは、明示的な`anchor`と対応する参照です。`let`変数や辞書で共有した点はソースで編集します。

## プレビューと文書全体の違い

通常のプレビューでは、選択キャンバスより前のimport、定義、設定を残し、通常の文章や先行キャンバスは省きます。単独化した定義だけでコンパイルできない場合は、元の前置き部分を使う方法へ切り替えるため、先行する文章が表示に含まれることがあります。

プレビュー用Typstのルートと作業ディレクトリは元の`.typ`があるフォルダーです。親フォルダーのファイルを読み込む文書は、この制約で失敗する場合があります。GUIには独自のTypstルートを指定する設定を用意していません。必要な資産を同じフォルダー以下へ置くなど、ソースの構成を調整します。

一方、出力コマンドは[文書全体](export.md)をコンパイルします。キャンバスだけのプレビューと出力範囲は異なります。

## 同期と変更の競合

Typstを直接編集するとGUIを更新します。カーソルの移動だけで仮想Draw.io文書を書き換えることはありません。

GUIは編集元のソース版と表示の版を照合します。古い表示からの変更や、削除済みの対象への要求は書き込まず、最新のソースへ同期します。Typstを直接編集した場合はGUI側の操作履歴をクリアします。両方を同時に大きく変更するときは、一方の反映を確認してから次を操作すると対応が分かりやすくなります。

3D平面内の変更では、選択body内への変更に限定し、文書全体と次のローカル表示を検証してから適用します。他の面やキャンバス外の文章を誤って書き換えないように確認します。

## CeTZのバージョン

GUI CeTZは既存のimportを維持し、自動でパッケージを更新しません。

| 項目 | バージョンによる差 |
| --- | --- |
| `boolean` | 0.4.2にはない。0.5.2以降を使用 |
| 3番目の基準平面 | 0.4.2は`on-yz`、0.5系は`on-zy`。生成コードはimportに合わせる |
| 15ツールと追加のパス関数 | 0.4.2／0.5.2を対象としたテストがある。Booleanは除く |
| 透視投影 | 使用中のCeTZの実際の描画・校正結果に従う。版によって見え方や距離計算に差がある |

教材では0.5.3を指定します。将来の全バージョンへの互換性を保証するものではありません。引数や描画の違いは、実際にimportしている版で確認してください。
