# トラブル対処

[ドキュメント一覧](README.md)

## ▶ GUI CeTZが表示されない

ファイルを`.typ`として保存し、GUI CeTZを有効にしてください。VS CodeのCodeLensを無効にしている場合は、コマンドパレットの **CeTZ: Open GUI Editor** から開けます。

認識の入口は`cetz.canvas(...)`です。CeTZの関数を別名で呼び出すなど、ソース上にこの形がない場合は、対応する記述へ調整してください。複数キャンバスの取り違えは、対象のCodeLensから開いて確認します。

## Typst CLI was not foundと表示される

VS Codeの統合ターミナルで`typst --version`を実行します。Typst CLIをインストールし、拡張機能を実行するVS Codeの環境からPATHで見つかるようにします。PATHを変更した後はVS Codeを再起動して確認してください。

## Draw.ioの普通の画面が開き、CeTZのパネルがない

Draw.io Integrationが有効か、初回のCeTZプラグインを許可したか確認します。GUIを開くと現在のプラグインを設定へ登録します。更新後は **Developer: Reload Window** を実行し、GUIを開き直してください。

Draw.ioの設定で`hediet.vscode-drawio.plugins`を確認する場合は、現在のインストール先の`src/cetz-drawio-plugin.js`が登録対象です。通常は手動で追加する必要はありません。

## 図が表示されない／コンパイルエラーが出る

まず保存した文書をターミナルでコンパイルし、Typstの診断を確認します。

```sh
typst compile drawing.typ /tmp/drawing-check.pdf
```

上の出力先はmacOS／Linuxの例です。他の環境では書き込み可能な出力先へ変更してください。CeTZの未取得パッケージ、import、参照名、フォント、画像のパス、引数の誤りなどを修正します。

文書全体はコンパイルできるのにGUIだけ失敗する場合は、[プレビューの単独化とルート](source-and-limitations.md)を確認します。大きな描画では、プレビューの1回のコンパイルが15秒を超えたり、SVGが約800万文字を超えたりすると中止します。まず小さいキャンバスへ分けて確認してください。

![個別編集できる円に青いハンドルとPropertiesが表示された正常時の画面](images/screenshots/03-select-circle.jpg)

正常時の例です。図形を選んでもこのようなハンドルやPropertiesが出ない場合は、以下の対応範囲を確認してください。

## 見えるが選択枠やハンドルが出ない

Typstの描画に成功しても、ソースへ安全に対応付けられない図形には編集枠が付きません。ループ、独自の生成関数、複雑な変換などがないか確認します。数値座標の単純な図形で動作を確認してから、[対応範囲](source-and-limitations.md)と照らし合わせてください。

3Dでは図形のクリックはその平面の選択です。平面内の図形を編集するには **Edit in 2D** を使います。

## ドラッグやサイズ変更が元に戻る

その変更がCeTZの引数へ書き戻せない可能性があります。アンカー式の図形のリサイズ、星の片方向拡大、文字枠による文字サイズ変更は対象外です。PropertiesまたはTypstで対応する値を変更してください。

ソースを編集した直後の古い画面から操作した場合も、表示を最新ソースに戻します。

## Propertiesの値が反映されない

数値や式が完成しているか、単位が必要な場所に`deg`や`pt`を付けているか、文字列を引用符で囲んでいるか確認します。テキスト入力は約400msの待機または確定後に検証します。未完成・不正な値は欄に保持し、直前の有効な描画を維持します。

日本語IMEは変換確定後に反映します。タブを切り替えられない場合も、未完成の欄を修正し、ソース更新を確認してください。任意項目を空欄にすると明示指定を取り除くため、スタイルの継承で見え方が変わる場合があります。

## パス操作が無効／適用できない

Booleanは閉じたパスを2つ以上、他の合成はパスを2つ以上選びます。選択物は同じグループに置きます。Frame selectionだけは1図形でも使えます。

Subtractの前後が逆ならOutlineのソース順を確認します。CeTZ 0.4.2ではBooleanを利用できません。途中の状態変更や、外部からのオペランド名参照がある場合は、ソースで調整してください。詳細は[パス操作](path-operations.md)にあります。

## 並び替え・グループ化を拒否される

先に必要なアンカー・変数定義、間にある`set-style`や変換、グループ化時のコメントなどを確認します。順序によって意味が変わるため、見た目の重なりだけで自由に移動できるわけではありません。

3Dで並び替えても見た目が変わらない場合は`sorted: true`による深度順の可能性があります。

## 3Dの操作が想像と違う

通常のドラッグは視点回転です。画面だけの移動はPan、平面の移動はXYZ矢印、平面内の図形の移動は2Dタブを使います。カメラ角度・位置の変更はソースと出力にも反映します。

XYZ作図で軸が画面に垂直だと、クリックでは位置を決められません。数値を入力してEnterで進みます。平面外参照や入れ子投影がある面を2Dで開けない場合は、ソースで編集してください。

## GUIが古い／更新版が動いていない

**CeTZ: Sync GUI From Typst** で同期します。VSIXを更新した場合は、GUI CeTZを使う各ウィンドウで **Developer: Reload Window** を実行します。プラグイン更新後は再度信頼確認が出ることがあります。

## 出力したら文章まで含まれた／グリッドが消えた

出力はTypst文書全体です。図だけにするには独立した`.typ`と自動ページサイズを使います。編集用のグリッド・座標軸・ハンドルは出力されません。必要なグリッドは`grid(...)`として描きます。[保存と出力](export.md)を参照してください。

## 不具合を再現して伝える

可能であれば、最小の`.typ`、GUI CeTZ・Draw.io Integration・VS Code・Typst・CeTZのバージョン、2D／3Dの別、実行した操作とエラー文を揃えてください。プライベートな文書から切り出す場合は、図を再現するのに必要な定義だけを残すと原因を絞れます。
